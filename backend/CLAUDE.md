# Backend Development Guide

## Model Configuration for Cost Efficiency

When working on backend code development tasks, use **OPENCODE** model for all coding operations to minimize token usage and reduce credits consumed.

### When to Use OPENCODE
- Writing and editing service files (`.js`, `.ts`)
- Creating middleware and utilities
- Database queries and ORM operations
- API endpoint development
- Configuration files and setup

### Usage Instructions

For cost-effective backend development:
- Use lighter models like Haiku or Sonnet for routine coding tasks
- Reserve premium models only for complex architecture decisions
- Prefer iterative, focused changes over large refactors
- Leverage OPENCODE model configuration for standard coding patterns

### Project Structure
- `/src/services/` - Business logic and service layer
- `/src/routes/` - API endpoints
- `/src/middleware/` - Request/response handlers
- `/src/models/` - Data models and schemas
- `/src/utils/` - Helper functions and utilities

## Notes
This backend uses OPENCODE approach for efficient development while maintaining code quality.
